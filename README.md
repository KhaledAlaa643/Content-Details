# E-Commerce Product Page

This is a simple e-commerce product page for a Men's Navy Blue Solid Sweatshirt.

## Image Requirements

For the page to display properly, you'll need to add the following images to the `images` folder:

- `main-product.jpg` - The main product image
- `thumbnail-1.jpg` - First thumbnail (same as main image)
- `thumbnail-2.jpg` - Second thumbnail (side view)
- `thumbnail-3.jpg` - Third thumbnail (front view)
- `thumbnail-4.jpg` - Fourth thumbnail (back view)
- `thumbnail-5.jpg` - Fifth thumbnail (detail view)

## Features

- Responsive design
- Product image gallery with thumbnails
- Add to cart functionality
- Mobile-friendly layout
